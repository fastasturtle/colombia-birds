| 18 | Вероятность и «интересные» (27.09) | Для каждой пары (вид, место) три состояния только по осенней (сен–ноя) частоте GBIF в радиусе локации: «Точно увидим» (`sure`, ≥ 1 % осенних записей птиц), «Возможно» (`maybe`, 0,1–1 %), «Вряд ли» (`unlikely`, < 0,1 %, < 3 осенних записей или вида нет в списке GBIF локации). Пороги — константы в `pipeline/common.py`. Для дня — лучшее состояние по локациям дня, для списка без места — лучшее по всем локациям маршрута. «Интересная» (★, бывшая «изюминка») — цель из отчётов о поездках для этой локации, эндемик Колумбии или вид с узким ареалом; от состояния не зависит, цели из отчётов не выкидываются (без записей GBIF — «вряд ли» + ★). На всех списках один фильтр «Точно · Точно и возможно · Все» + «Только интересные» (по умолчанию «Точно и возможно»), выбор общий для сайта (`localStorage` `cb.filter`). |
