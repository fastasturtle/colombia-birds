# Факт-чек портретов семейств, партия 3 (2026-09-28)

Файлы: momotidae, nyctibiidae, odontophoridae, opisthocomidae, parulidae, passerellidae, pelecanidae,
phaethontidae, picidae, pipridae, podicipedidae, procellariidae, psittacidae.

Метод: счёт видов по `data/species_index.json` (поле `family`) и `data/families.json` (`species_count`);
все виды из `route_note` и тела сверены с `data/site_species.json` (sure/maybe) и `target_species` в
`data/sites_resolved.json`, дни по `data/itinerary.json`; факты по `data/texts/<slug>.json` (Wikipedia en/es/ru,
CC BY-SA 4.0) и проверенным карточкам `content/species/`; веб только для двух пунктов (ниже). Схема портретов
(`content/families/README.md`, `site/src/lib/content.ts`) не описывает поле `sources:`, поэтому источники
перечислены только здесь. Русские названия семейств совпадают с `data/families.json` (кроме Passerellidae, где там
`null`, см. Data issues).

## Data issues

- `data/families.json`: у Passerellidae (passer3) `names.ru` = null (и в data/sources/family_names.json); портрет
  пишет «семейство без устоявшегося русского названия» — нужно решение по русскому названию (напр. «Американские
  овсянки»).
- Цели локаций, которые site_species не подтверждает даже как maybe: nyctibius-grandis (El Escondite),
  podiceps-occipitalis (Laguna La Cocha), veniliornis-chocoensis (Río Ñambí), touit-stictopterus (El Encanto),
  atlapetes-leucopis (Trampolín), phaethon-aethereus и procellaria-parkinsoni (Playa del Morro). Стоит пересмотреть
  `target_species` или отметить их как «редкие цели».
- Несогласованность между портретами (не в моей партии): content/groups/parrots.md пишет, что «амазоны и пионы»
  летят «с неглубокими частыми взмахами», а карточки pionus-* и families/psittacidae.md — что у Pionus взмахи
  глубокие. Группу нужно поправить.
- species_count в families.json включает гипотетические и вымершие виды (parulidae 57, pipridae 23, podicipedidae 4
  с вымершей Colombian Grebe); портреты теперь следуют этим числам с оговорками.
