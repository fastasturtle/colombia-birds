## По видам

- tringa-melanoleuca — сроки пребывания «с сентября по апрель» по общим знаниям; marks включают streaked_breast (зимой пестрины слабые).
- tringa-semipalmata — голос «кьи-йии», «ки-ри-рит» по памяти; bill [long, thick] пограничный (Wikipedia: «shortish, heavy»).
- pluvialis-squatarola — «самая крупная ржанка Колумбии» по общим знаниям (сравнить с P. dominica, Hoploxypterus); отличие от P. dominica (подмышки, надхвостье) по памяти.
- calidris-alba — отличия от C. mauri по памяти.
- charadrius-semipalmatus — отличия от anarhynchus-collaris (нет белого ошейника на затылке, ноги бледные) и anarhynchus-wilsonia по памяти; «местные ржанки с одной полосой на груди» на пляжах Тумако — проверить, какие реально встречаются (Collared, Wilson's).
- calidris-minutilla — «самый маленький кулик в мире» по Wikipedia («the smallest shorebird»); отличия от C. pusilla/C. mauri по памяти.
- tringa-solitaria — «белые бока хвоста в полосках» и отличия от Tringa flavipes по памяти; согласовано с карточкой actitis-macularius.
- haematopus-palliatus — голос по памяти; подвид на тихоокеанском побережье Колумбии (pitanay?) не указан.
- leucophaeus-atricilla — «главная чайка нашего участка побережья» по данным site_species (sure в Тумако и Плайя-дель-Морро); отличия от Franklin's Gull по Wikipedia; голос зимой по памяти.
- jacana-jacana — подвид на тихоокеанской стороне Нариньо (melanopygia? scapularis?) и фраза «спина может быть заметно темнее, чем у амазонских» — проверить; Wikipedia: melanopygia «western Colombia», nominate «southern Colombia».
- himantopus-mexicanus — голос по памяти.
- larosterna-inca — голос по памяти; статус в Колумбии: Wikipedia (SACC — hypothetical) против ACO «Errática»; проверить, есть ли подтверждённые записи у Тумако.
- patagioenas-fasciata — «дубравы» как биотоп в Колумбии по общим знаниям; подвид в Нариньо (albilinea) не упомянут.
- crotophaga-ani — отличие от C. sulcirostris (голос «ти-хо») по памяти.
- columba-livia — формулировка «родом из Европы, Северной Африки и Южной Азии» сокращена по Wikipedia.
- patagioenas-cayennensis — подвид в Колумбии и цвет подхвостья (серый у номинативного, белый у andersoni) — в тексте «беловато-серые»; проверить.
- patagioenas-plumbea — голос: конкретная транскрипция песни и отличие по ритму от P. subvinacea не даны, проверить и уточнить; «окраска рыжее» у subvinacea по памяти.
- columbina-talpacoti — «почти нет на побережье у Тумако» по карточке columbina-buckleyi и data; отличие от claravis-pretiosa по Wikipedia.
- piaya-cayana — цвет голого кольца вокруг глаза у колумбийских подвидов (жёлто-зелёное или красное) не указан намеренно; проверить и при желании добавить.
- coccyzus-americanus — «зимует в основном южнее Колумбии», сроки пролёта сентябрь–ноябрь по общим знаниям.
- zentrygon-linearis — отличие от Z. frenata («крупнее, горло чисто белое, темя голубовато-серое, выше по склону») по Wikipedia и памяти; marks [eyebrow] условно (серая дуга от глаза к затылку).
- neomorphus-radiolosus — окраска низа: Wikipedia описывает «underparts black with the same scaly appearance», в карточке «низ в белой чешуе на чёрном» — сверить с фото; голос («низкое голубиное «ууу»») по памяти; статус: Wikipedia «vulnerable», ACO/data EN; отличие от N. geoffroyi («тёмная полоса поперёк груди») по памяти.
- geotrygon-saphirina — голос по памяти; «очень локальный вид Путумайо» — по Wikipedia «far southern Colombia»; group-портрет называет Исла-Эскондиду, а в data там unlikely (n=9) — согласовать.
- ortalis-guttata — голос по памяти; согласовано с карточками ortalis-columbiana и opisthocomus-hoazin.
- ortalis-erythroptera — «вероятно, лучшая возможность увидеть вид в Колумбии» — вывод из data (sure у Км 42); проверить.
- tinamus-major — «поёт у лоджа Исла-Эскондиды» по content/families/tinamidae.md; подвид в Путумайо не указан.
- tinamus-osgoodi — высоты 1 400–2 100 м для hershkovitzi по Wikipedia, в data 600–2 100; подвид и точки (Уила, Какета) по Wikipedia. Family-портрет называет вид целевым в Исла-Эскондиде и на Трамплине птиц, а в data везде unlikely — согласовать.
- psophia-crepitans — голос («ум-ум-ум-ууу») по памяти; подвид napensis в Путумайо по Wikipedia (SE Colombia).
- ortalis-cinereiceps — голос по памяти; вид вне маршрута, карточка ради сравнения.
- hydropsalis-climacocerca — описание оперения, голос и отличия от Pauraque и Band-tailed Nighthawk по памяти (в выдержке Wikipedia нет раздела Description); «днём сидит на песке речных кос» по общим знаниям.

## Data issues

- patagioenas-cayennensis — русское имя в data `names.ru` = «Рыжспинный голубь» (опечатка, вероятно «Рыжеспинный»); в карточке использовано только английское имя.
- piaya-cayana — `names.ru` = null; в карточке только английское имя.
- coccyzus-americanus — `names.ru` = «Желтоклювая пиайя» (eBird); род Coccyzus, не Piaya, в русской литературе обычно «желтоклювая американская кукушка». Использовано имя из data, проверить.
- haematopus-palliatus — `traits.elevation_m.max` = "L" (строка вместо числа); geotrygon-saphirina, crypturellus-bartletti и др. — `elev.min` = "L". Похоже на недоразобранный код BIRDBASE («lowlands»).
- jacana-jacana — `habitat_aco` = "Marine"; psophia-crepitans — `habitat_aco` = "Coastal"; columba-livia — `habitat_aco` = "Woodland". Вероятно, сдвиг/ошибка маппинга ACO.
- piaya-cayana — `names.en` = Common Squirrel-Cuckoo, `en_aco` = Squirrel Cuckoo (сплит P. mexicana); не ошибка, но сайт показывает eBird-имя.
- larosterna-inca — `elevation_m` 0–0 и статус «Errática»; SACC считает вид для Колумбии гипотетическим.
