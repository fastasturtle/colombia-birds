# Факт-чек портретов семейств, 28.09.2026, партия 1

13 портретов: accipitridae, alcedinidae, anatidae, apodidae, ardeidae, bucconidae, capitonidae, caprimulgidae,
cardinalidae, columbidae, corvidae, cotingidae, cracidae. Правки внесены сразу в ru и en. Поля `sources:` в схеме
портретов нет (content/families/README.md), поэтому источники указаны только здесь.

Общие источники для всех файлов: data/species_index.json (число видов по `family`, статусы), data/site_species.json
(состояния sure/maybe по точкам), data/sites_resolved.json (`target_species`), data/itinerary.json (дни),
data/families.json (русские названия), data/texts/<slug>.json (извлечения Wikipedia, CC BY-SA 4.0), проверенные
карточки видов в content/species/.

Числа видов теперь даются как «в колумбийском списке N видов» с оговоркой о залётных и неподтверждённых видах там,
где они есть (species_index: статусы vagrant/hypothetical).
