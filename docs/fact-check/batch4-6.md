## Общее

- Голоса, не описанные в выдержках Wikipedia, даны обобщённо по памяти: sporophila-castaneiventris, pheugopedius-mystacalis, progne-tapera, cinclus-leucocephalus, hylophilus-flavipes, cyanolyca-armillata, anthus-bogotensis (токовый полёт), amazona-amazonica («кви-кви»), amazona-autumnalis, pionites-melanocephalus, amazona-ochrocephala («низкие раскатистые»), forpus-crassirostris, psittacara-wagleri, eupsittula-pertinax, ara-severus («краа-ак»).
- `feeder` не поставлен никому. Cyanocorax yncas местами ходит на фруктовые кормушки лоджей; проверить, бывает ли это в Эль-Энканто или Ла-Дримофиле.
- Пограничные размерные классы: progne-tapera = thrush (16–18 см, как progne-chalybea); psittacara-wagleri = pigeon (около 36 см, по аналогии с leucophthalmus 32–35 см); eupsittula-pertinax = pigeon (23–28 см, по аналогии с aratinga-weddellii); nyctibius-griseus = crow (34–38 см); amazona-ochrocephala = pigeon (33–38 см).
- Подобраны похожие виды без карточек и без выдержек Wikipedia (отличия по памяти): sporophila-nigricollis, pyrilia-barrabandi, pionus-tumultuosus, ara-militaris, anthus-chii, pachysylvia-semibrunnea, nyctibius-aethereus, dendrocygna-autumnalis, dendrocygna-viduata, troglodytes-aedon.

## По видам

- sporophila-castaneiventris — отличие от S. angolensis по Wikipedia (самец чёрный сверху, белое пятно на крыле); отличие от S. nigricollis и голос по памяти. tone bright — пограничный выбор.
- campylorhynchus-turdinus — клюв помечен [medium, curved] («slightly decurved», «relatively long»); проверить, не лучше ли [long, curved].
- cyanocorax-yncas — какой подвид в Уиле (galeatus / yncas / cyanodorsalis), в карточке не указан. «Над клювом синий хохолок» — по описанию колумбийских подвидов в Wikipedia (у всех есть лобный хохол), проверить для южной Уилы. Утверждение, что многие списки выделяют Inca Jay в отдельный вид, — по Wikipedia (IOC/BirdLife), проверить формулировку.
- tachycineta-albiventer — colors [blue, white, black]: сине-зелёный верх отнесён к blue.
- turdus-leucomelas — «рыжеватые подкрылья» по памяти и по карточке turdus-ignobilis; в выдержке Wikipedia только «wing coverts slightly rustier».
- vireolanius-leucotis — какая форма в Исла-Эскондиде (leucotis, по Wikipedia «крайний юго-восток Колумбии»; проверить, заходит ли она на предгорья Путумайо); у Бангсиас-лоджа — mikettae. Отличие от Cyclarhis по памяти.
- pheugopedius-mystacalis — голос (дуэт, повторяемые фразы) по памяти; какие подвиды на маршруте (macrurus у Чикаке и в Уиле? mystacalis/yanachae на юге) — в текст не вынесено.
- cyclarhis-gujanensis — ru-название в data «Краснобровый попугаевый виреон», в ru Wikipedia «попугайный»; в карточке оставлено как в data.
- turdus-fulviventris — «единственный Turdus с рыжим брюхом в северных Андах» — по Wikipedia.
- progne-tapera — сезон присутствия мигрантов fusca в Колумбии (в тексте осторожно: «зимой южного полушария»); к октябрю большинство, вероятно, уже улетело на юг — проверить. Голос по памяти.
- troglodytes-solstitialis — граница подвидов solitarius / solstitialis на юге Колумбии (Путумайо, Нариньо) по Wikipedia, проверить для Трамплина и Ла-Коча.
- turdus-serranus — высоты: data 1 400–2 800 м (extreme 900–3 750), в тексте Wikipedia для Колумбии 1 400–3 000 м.
- riparia-riparia — «в сентябре–октябре стаи идут на юг» по памяти; высоты data 0–2 100 м (extreme 4 500).
- pheugopedius-sclateri — отличие от P. mystacalis и H. leucophrys по Wikipedia и памяти; вид в Чикаке при высотах парка 2 000–2 700 м (см. Data issues).
- cinclus-leucocephalus — «не ныряет, а окунает голову» по Wikipedia; голос и «часто пролетает низко над потоком» по памяти. У подвида leuconotus по Wikipedia белое идёт на брюхо — в key_features сказано только «горло и грудь белые».
- hylophilus-flavipes — голос по памяти; отличия от pachysylvia-semibrunnea и vireo-leucophrys по памяти.
- cyanolyca-armillata — голос по памяти; подвид quindiuna на юге (Сибундой, Трамплин) по Wikipedia; отличие от C. turcosa согласовано с карточкой turcosa.
- anthus-bogotensis — «единственный конёк высокогорий Колумбии» и токовый полёт с песней по памяти; высоты в Колумбии 3 100–3 600 м по Wikipedia (data 2 100–4 200 м).
- brotogeris-cyanoptera — «один из самых обычных мелких попугаев низин» по памяти.
- psittacara-leucophthalmus — «в низинах Путумайо встречается изредка» — вывод из data (unlikely в Пуэрто-Асисе и др.).
- amazona-amazonica — оранжевое зеркальце по en/es Wikipedia; ru Wikipedia пишет «красная полоса на маховых» — проверить. Высоты data 0–600 м (extreme 800).
- amazona-autumnalis — «у колумбийских птиц (salvini) щёки в основном зелёные» и объяснение русского имени по памяти; проверить. Вид на Финке Марагрикола — по data.
- pionites-melanocephalus — голос по памяти; отличие от pyrilia-barrabandi по памяти (выдержки нет).
- amazona-ochrocephala — голос по памяти; отличия согласованы с карточкой amazona-farinosa.
- forpus-crassirostris — нет русского имени в data (ru = None), в тексте используется английское; таксономический статус (отдельный вид в Clements, подвид F. xanthopterygius в ряде списков) по Wikipedia.
- psittacara-wagleri — нет data/texts: вся карточка по data и памяти. Проверить окраску (красные бёдра и сгиб крыла у части птиц), гнездование колониями на скалах, голос. Русского имени в data нет.
- eupsittula-pertinax — окраска восточноколумбийского подвида lehmanni по Wikipedia; «необычна во влажных низинах Путумайо» — вывод агента (см. Data issues).
- ara-severus — голос по памяти; «пары прилетают на глинистые обнажения» по памяти.
- amazona-mercenarius — ru-имя в data «Солдатский амазон» (совпадает с ru Wikipedia, но легко спутать с «солдатским ара» Ara militaris); подвид в Колумбии (canipalliata?) не указан; отличие от pionus-tumultuosus по памяти.
- dendrocygna-bicolor — «держится вместе с красноклювыми древесными утками» и «стоит почти вертикально, как гусь» по памяти.
- nyctibius-griseus — «поёт в лунные ночи» по памяти; «ряд чёрных пятен на груди» согласован с карточкой nyctibius-grandis; отличие от N. aethereus по памяти.
- crypturellus-undulatus — какой подвид в Путумайо (yapura по es Wikipedia: «от Эквадора до запада Бразилии»); отличия согласованы с карточками cinereus, soui и tinamus-major.

## Data issues

- hylophilus-flavipes — «maybe» в Чикаке (4,2 ‰), хотя парк лежит на 2 000–2 700 м, а вид по Wikipedia в Колумбии до 1 000 м (data до 1 500 м). Вероятно, записи с нижних сухих склонов в радиусе 7 км; стоит проверить радиус Чикаке или сузить.
- turdus-leucomelas — «maybe» в Чикаке (8,8 ‰) при высотах вида до 1 500 м (extreme 2 000) — та же причина.
- pheugopedius-sclateri — «maybe» только в Чикаке при высотах вида 1 300–2 000 м; mass_g в data = null.
- eupsittula-pertinax — «maybe» в Эль-Эскондите (Путумайо, 350–450 м): вид открытых сухих ландшафтов, для амазонского Путумайо необычен; возможна путаница с aratinga-weddellii в исходных наблюдениях.
- amazona-ochrocephala — «maybe» в Ла-Флориде (Богота, 2 540 м) при высотах вида до 300 м (extreme 850): скорее всего, беглые клеточные птицы.
- forpus-crassirostris — в data elevation min = "L" (строка вместо числа), mass_g = null, names.ru = None.
- psittacara-wagleri — нет data/texts (выдержек Wikipedia), names.ru = None.
- progne-tapera — habitat_aco = «Forest», хотя вид открытых мест; cyanocorax-yncas — habitat_aco = «Grassland»; riparia-riparia — «Human Modified». Похоже на сдвиг поля в маппинге ACO.
- amazona-autumnalis — ru «Желтощёкий амазон» из eBird при ru Wikipedia «Краснолобый амазон»; для колумбийских птиц без жёлтых щёк имя вводит в заблуждение.
- cyclarhis-gujanensis — ru-имя «попугаевый» (data) против «попугайный» (ru Wikipedia).
