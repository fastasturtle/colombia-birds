# Факт-чек: партия 5, список 4 (муравьянки, печниковые, попугаи, голуби, кукушки, певчие)

Карточки написаны 27.09.2026 по data/species, data/texts (Wikipedia en) и полевым знаниям агента.
Ниже то, что стоит проверить по открытым источникам перед публикацией. Формат: `slug — что проверить`.

## Общее

- Голоса по памяти (в выдержках Wikipedia нет раздела или он не про Колумбию): premnornis-guttuliger, xiphorhynchus-guttatus, microrhopias-quixensis, phlegopsis-nigromaculata, sclerurus-obscurior, thamnistes-anabatinus, cyclarhis-nigrirostris, pheugopedius-coraya, turdus-albicollis, catharus-minimus (выдержка обрезана), petrochelidon-pyrrhonota, pachysylvia-semibrunnea (выдержка обрезана), catharus-aurantiirostris, turdus-leucops, cantorchilus-leucotis, cyphorhinus-arada, pachysylvia-hypoxantha, columbina-minuta, crotophaga-sulcirostris, coccycua-minuta (песня), geotrygon-montana, pionus-sordidus.
- size на границах классов: catharus-minimus (16–17 см) и catharus-aurantiirostris (15,5–17 см) поставлены thrush «по облику дрозда»; campylorhynchus-zonatus (16,5 см по Wikipedia) — thrush; geotrygon-purpurata (22–26 см) и geotrygon-montana (19–28 см) — thrush, хотя птицы плотные, 125–155 г; coccycua-minuta (≈27 см с хвостом, 40 г) — thrush, а не pigeon; microrhopias-quixensis (10–12,5 см) — sparrow.
- tone спорный: turdus-leucops и petrochelidon-pyrrhonota — dull (по аналогии с turdus-serranus), campylorhynchus-zonatus и geotrygon-purpurata — bright.

## По видам

- premnornis-guttuliger — позыв «цит» по памяти; «по стволам не лазает, хвост как опору не использует» — вывод из описания кормления в Wikipedia, проверить.
- xiphorhynchus-guttatus — в Путумайо группа «Lafresnaye's» (guttatoides): цвет клюва («светлее у основания подклювья») и отсутствие пятен на горле описаны по номинативной форме; проверить для guttatoides. Песня «смеющаяся нисходящая серия» и позыв «чу-рит» по памяти.
- margarornis-stellatus — голос в Wikipedia не описан, в карточке общая формулировка; «Central Andes» в ареале — по Wikipedia (Chocó и Antioquia), проверить для Нариньо.
- microrhopias-quixensis — similar myrmotherula-schisticolor: описание самки («охристая, без чёрного горла») по памяти.
- phlegopsis-nigromaculata — на Плайя-Рике (р. Путумайо) возможна и P. erythroptera? Проверить, не путаются ли записи.
- sclerurus-obscurior — «недавно отделили от Middle American Leaftosser»: в NACC/HBW эти формы до сих пор в S. mexicanus; какой подвид на Ла-Планаде (obscurior или andinus) — спорно, в карточке не назван.
- thamnistes-anabatinus — данные дают max 400 м (экстрем. 1 500), а Исла-Эскондида в предгорьях; проверить высоты вида на восточном склоне Путумайо. Голос по памяти.
- cyclarhis-nigrirostris — «клюв тёмный или черноватый» (в Wikipedia «black-tipped bill»); сходство песни с C. gujanensis по памяти.
- pheugopedius-coraya — подвид в Путумайо (griseipectus или caurensis) не назван; «белые штрихи на щеках» по Wikipedia для вида в целом.
- vireo-flavoviridis — «в начале октября основной поток идёт через страну на юг» — вывод из «most depart southwards by mid-October»; проверить сроки пролёта в Колумбии. similar vireo-leucophrys: отличия взяты из карточки vireo-olivaceus.
- turdus-albicollis — у подвида spodiolaemus цвет клюва (в Wikipedia жёлтый у номинативного) не указан в карточке; цвет кольца вокруг глаза у spodiolaemus проверить. Позыв «квок» по памяти.
- catharus-minimus — «осенний пролёт в октябре» по памяти; позывы по памяти.
- petrochelidon-pyrrhonota — «летит прямее, с большим числом планирований» по памяти.
- pachysylvia-semibrunnea — отличия P. decurtata и P. aurantiifrons по выдержкам Wikipedia; голос по памяти.
- catharus-aurantiirostris — какой подвид в Эль-Энканто/Ла-Дримофиле (insignis? phaeopleurus?) — не назван. similar catharus-fuscater: «радужка светлая» по памяти (в выдержке нет).
- cinnycerthia-olivascens — какой подвид на Трамплине птиц (восточный склон Путумайо); «иногда со смешанными стаями» по памяти.
- turdus-leucops — песня по памяти; ареал «верхняя долина Магдалены» по Wikipedia, но на маршруте вид отмечен только на Ла-Планаде (тихоокеанский склон).
- cantorchilus-leucotis — см. «Data issues» (Чикаке).
- cyphorhinus-arada — «толстый клюв с высоким гребнем» по памяти; «самая красивая песня Амазонии» — оценочно.
- campylorhynchus-zonatus — высоты в Колумбии (данные до 3 000 м, Wikipedia до 1 700 м для Центральной Америки); окраска брюха «коричная» по Wikipedia для номинативной формы, у колумбийского brevirostris проверить.
- catharus-fuscescens — «зимует прежде всего в Бразилии» по памяти.
- pachysylvia-hypoxantha — голос по памяти; similar hylophilus-thoracicus и tunchiornis-ochraceiceps: «глаз светлый» по памяти.
- columbina-minuta — отметка «возможно» на Финке Дискосура (Путумайо, амазонские предгорья): проверить, не путаница ли с C. talpacoti.
- geotrygon-purpurata — «уходит пешком, не взлетая» по памяти (типично для перепелиных горлиц).
- zentrygon-frenata — «тёмная полоска под щекой» у подвида bourcieri по памяти; «взлетает с громким хлопаньем крыльев» по памяти.
- crotophaga-sulcirostris — голос C. ani («ноющее восходящее «уи-ик»») по памяти; в карточке crotophaga-ani голос sulcirostris записан как «ти-хо», согласовано.
- coccycua-minuta — песня «хриплая нисходящая серия» по памяти.
- geotrygon-montana — голос («как дуют в горлышко бутылки») и красноватые клюв и ноги по памяти.
- pionus-sordidus — голос по памяти.
- ara-militaris — «уязвимый (VU)» по индексу проекта; причины (вырубки, отлов) по памяти, раздел Conservation в data/texts не прочитан целиком.

## Data issues

- cantorchilus-leucotis — единственная точка маршрута «возможно» — Чикаке (облачный лес ~2 000–2 700 м), при высотах вида до 950 м. Вероятно, в радиус 7 км попадают тёплые долины ниже по склону (Тена, Ла-Меса); в тексте это оговорено.
- campylorhynchus-zonatus — «возможно» в Чикаке и elevation_m.max = 3 000 при min = 0: для этого вида верхняя граница выглядит завышенной.
- margarornis-stellatus — английское имя в данных «Fulvous-dotted Treerunner», в Wikipedia «Star-chested Treerunner»; в карточке указаны оба.
- sclerurus-obscurior — в данных «South American Leaftosser», в Wikipedia «Dusky Leaftosser»; в карточке указаны оба.
- cinnycerthia-olivascens — русское «оливковый крапивник» не соответствует окраске (птица бурая, не оливковая), но оставлено по данным.
- microrhopias-quixensis — русское «бархатный алапи» выглядит странно для вида Microrhopias, оставлено по данным (eBird).
- vireo-flavoviridis, catharus-minimus, catharus-fuscescens, petrochelidon-pyrrhonota — основные «возможно» приходятся на необязательные точки у Боготы (Ботанический сад, Ла-Флорида, Сумапас, Чингаса, Обсерватория колибри); на маршруте тура у мигрантов шансы невысоки.
- xiphorhynchus-guttatus — таксономия: HBW/BirdLife относит птиц Путумайо к X. guttatoides (Lafresnaye's Woodcreeper); в данных ACO/Clements — X. guttatus.
