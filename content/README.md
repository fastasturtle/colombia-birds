# Рукописный контент

Пишется агентами, сливается с `data/` при сборке сайта. Формат:

## `content/species/<slug>.md` — карточка вида

Слаг = `id` из `data/species_index.json`. Сайт читает и проверяет карточки при сборке (`site/src/lib/content.ts`,
`site/src/lib/traits.ts`): ошибка схемы или признак вне словаря роняет `npm run build` с именем файла.
Пример: `content/species/grallaria-hypoleuca.md`.

```markdown
---
id: grallaria-hypoleuca            # обязательно, = имя файла и id в data/species_index.json
difficulty: medium                 # easy | medium | hard — насколько легко узнать в поле
lynx_page: null                    # ручное переопределение страницы в Lynx «Birds of Colombia» (Hilty 2021); по умолчанию null — сайт берёт lynx_page из data/species_index.json
checked: 2026-09-27                # необязательно: дата последнего факт-чека (YYYY-MM-DD), на сайте не показывается; сводка — scripts/card_index.py → docs/fact-check/INDEX.md
key_features:                      # 3–5 признаков, каждый начинается с признака, ≤ 20 слов
  - "Горло и брюхо чисто белые, без пестрин"
similar:                           # похожие виды: id из индекса (лучше с маршрута) и отличие одной фразой
  - id: grallaria-ruficapilla
    how: "грудь в крупных тёмных пестринах, голова ярче каштановая"
behavior: "1–2 предложения: где держится и что делает"
voice: "1 предложение: голос словами"
traits:                            # словарь определителя, см. ниже
  size: thrush
  colors: [rufous, white, gray]
  tone: dull
  marks: [short_tail, plain]
  bill: medium
  layer: [ground, understory, feeder]
sources:                           # что использовано; тексты Wikipedia — с лицензией
  - "Wikipedia: White-bellied antpitta (en, CC BY-SA 4.0)"
  - "Данные проекта: data/species/grallaria-hypoleuca.json (ACO 2022, BIRDBASE 2025)"
en:                                # английское зеркало, те же id в similar и в том же порядке
  key_features: ["..."]
  similar: [{ id: grallaria-ruficapilla, how: "..." }]
  behavior: "..."
  voice: "..."
---
Текст по-русски, 60–120 слов: где и на каких высотах живёт, чем выделяется, где искать на маршруте
(локации и даты из data/site_species.json / study_lists.json).

## English

The same text in English.
```

Отдельной врезки «для новичка» нет (поле `beginner_note` удалено 27.09, сборка падает, если оно есть в карточке): подсказки для начинающего пишутся прямо в тексте, голосом полевого определителя, без снисходительного тона и без повтора `key_features` (образ вроде «в тени кажется просто чёрным, первыми видны белые пятна на груди» — в абзац).

Факты — из `data/species/<slug>.json`, `data/texts/<slug>.json` (Wikipedia, CC BY-SA, указать в `sources`) и общих
знаний; из защищённых определителей (Lynx, Birds of the World, eBird) не копировать. Стиль и термины — скилл `polish`.

### `traits` — закрытый словарь определителя

Словарь с русскими подписями — `content/traits.yaml` (его читает страница `/identify/`). Значение вне словаря или
неверное число значений в группе — ошибка сборки. Одно значение можно писать строкой, несколько — списком.

| Группа | Сколько | Значения |
|---|---|---|
| `size` | 1–2 | `hummingbird` «колибри и крошки» (любой колибри; прочие короче 10 см), `sparrow` 10–16 см, `thrush` 17–25, `pigeon` 26–35, `crow` 36–55, `larger` от 56; второй класс — только соседний, см. правила |
| `colors` | 1–3 | `black gray brown rufous olive yellow orange red blue green white purple` — главные цвета, заметные в поле, по убыванию площади |
| `tone` | ровно 1 | `bright` (насыщенные цвета или резкий контраст) · `dull` (приглушённая, однотонная, в т. ч. белые цапли) |
| `marks` | 0 и больше | `crest cap eye_ring eyebrow mask wing_bars wing_patch streaked_breast spotted_breast barred long_tail short_tail forked_tail white_tail_tips rump_patch throat_patch bare_face wattle bright_bill plain` |
| `bill` | 1–2 | `short medium long curved hooked thick thin flat hummingbird_long` |
| `layer` | 1 и больше | `ground understory midstory canopy water air feeder night` |

Правила разметки (ревизия словаря 27.09.2026, разбор и переразметка — `docs/fact-check/traits-retag-brief.md`):
- Размер — по полной длине из справочников (Wikipedia в `data/texts/<slug>.json`, раздел Description). Границы
  классов: короче 10 см — `hummingbird`, 10–16,9 — `sparrow`, 17–25,9 — `thrush`, 26–35,9 — `pigeon`, 36–55,9 — `crow`,
  от 56 — `larger`. Ровно 10 см — уже `sparrow`.
  - Все колибри — только `hummingbird`, даже длиннохвостые и с длинным клювом (Giant Hummingbird 20–23 см тоже).
    Прочие птицы попадают в `hummingbird`, только если короче 10 см (пикулеты, мухоловки-тоди 9–10 см).
  - Второй класс ставится, только если он соседний и выполнено одно из условий: (а) опубликованный диапазон длины
    переходит границу класса (Myiozetetes 16–18 см → `[sparrow, thrush]`; Club-winged Manakin 9,5–10 см →
    `[hummingbird, sparrow]`; эуфония 9–11 см → `[hummingbird, sparrow]`); (б) хвост — половина длины и больше или
    есть косицы: к классу по полной длине добавляется класс на ступень меньше, по телу (Asthenes fuliginosa 18–20 см →
    `[sparrow, thrush]`; Rufous Motmot 42–47 см → `[pigeon, crow]`; Barn Swallow 17–19 см → `[sparrow, thrush]`).
    Трогоны, якамары, туканы и крупные морские птицы (фрегат) по хвосту не понижаются. Больше двух классов не бывает:
    если диапазон уже дал два, правило хвоста не применяется; в `hummingbird` оно не опускает. Одно число без
    диапазона — один класс.
  - Нет длины ни в карточке, ни в `data/texts` — один класс «как поставит человек в поле» (Great Thrush ≈ 30 см — `pigeon`).
- `colors` и `tone` описывают взрослого самца в наряде, который виден на маршруте в октябре. Если самка резко
  отличается, её цвет можно добавить третьим. У перелётных видов с севера (`status: boreal_migrant` в
  `data/species/<slug>.json`) это осенний, зимний или первогодний наряд, а не брачный (Scarlet Tanager — оливково-жёлтый
  с чёрными крыльями, не алый; куличики — серые или бурые, без брачных пятен); `key_features` называют наряд
  («осенью…», «зимой…»). То же для местных видов с сезонным нарядом (Andean Gull, Pied-billed Grebe): если наряд
  в октябре не известен, цвета покрывают оба, а `key_features` описывают оба.
- Оттенков вне словаря нет, их сводим к ближайшему: охристый, коричный, каштановый → `rufous`; розовый → `red`
  (сиренево-розовый → `purple`); медный, бронзово-золотой → `orange`; серебристый, сизый → `gray`; бирюзовый — `blue`
  или `green` по преобладающему тону.
- `tone: bright` — насыщенный цвет на заметной части тела или резкий контраст, видный издали; яркий клюв или глаз
  сами по себе окраску яркой не делают.
- Приметы (`marks`): ставим все, что заметны в поле у взрослого самца (и самки, если она отличается), по одной на
  признак. `cap` — темя или вся голова резко другого цвета, чем спина и грудь (не ставится, если это только маска через
  глаз — тогда `mask`, или только горло — `throat_patch`); `wing_patch` — пятно, а не две узкие полосы (`wing_bars`);
  `bright_bill` — яркий весь клюв, его заметная половина (красное подклювье колибри) или лобный щиток.
  `plain` — оперение тела без пятен, пестрин и полос; сочетается со структурными приметами (`short_tail`, `crest`),
  мелкими метками на голове (`eye_ring`) и с `bright_bill`, но не с `cap` и `wing_patch`. Пустой `marks` допустим,
  только если ни одна примета не подходит и птица при этом не однотонная.
- `bill`: длина относительно головы; у колибри вместо `long` — `hummingbird_long` (клюв заметно длиннее головы),
  `hooked` — крючок на конце надклювья (цветоколы, хищники), `thick` — массивный (бородатки, туканы, вьюрки).
  Цвет клюва — в `marks` (`bright_bill`), не здесь.
- `layer`: где птицу обычно видят; `night` — активна ночью. `feeder` — только при подтверждении для маршрута: вид
  назван у кормушек точки маршрута в источнике (карточка, `docs/fact-check/`, `route_note` портрета семейства или
  группы) либо отмечен «точно» (`data/site_species.json`) на точке с кормушками подходящего корма из `data/sites.json`
  (нектар: observatorio-colibries, chicaque, finca-discosura, aves-y-florez, la-nutria, el-encanto; фрукты:
  aves-y-florez, el-encanto, la-nutria; черви: la-drymophila) и высота вида захватывает высоту кормушки. Общего знания
  «ходит на кормушки где-то в Андах» мало: тогда `feeder` не ставим. Отшельников (Phaethornis, Androdon) — только по
  прямому источнику. `feeder` всегда в паре с естественным ярусом.
- Словарь закрытый и меняется редко и осознанно. Новое значение добавляется только когда без него целая группа птиц
  неразличима в определителе, одним решением после ревизии (см. docs/TODO.md), не по ходу написания карточек.
  При добавлении: правь `content/traits.yaml` и эту таблицу вместе, запиши в traits.yaml дату и причину, прогони
  сборку и обязательно сделай проход переразметки по всем существующим карточкам (один агент на ~200 карточек, только
  по тексту карточек, без веба): иначе в определителе старые виды исчезнут при выборе нового чипа. Удаление или
  переименование значения сборка проверит сама — покажет карточки, где оно осталось.

## `content/similar/<slug-a>--<slug-b>.md`

Сравнение двух (или группы) похожих видов: таблица признаков, на что смотреть первым делом.

## `content/vocabulary.yaml` — английские слова бёрдера

Карточки и словарик на странице `/words/` (читает `site/src/lib/vocabulary.ts`; пустые `en`/`ru`, повтор слова или
неизвестный id вида в `examples` роняют сборку). Список записей:

```yaml
- en: rump                    # слово как в тексте; можно из двух слов (wing bar, cloud forest)
  ru: надхвостье             # короткий перевод, 1–4 слова, орнитологический термин
  note: низ спины над хвостом; -rumped — -гузый   # необязательно: короткая подсказка по-русски
  freq: 614                  # сколько английских названий видов + текстов Wikipedia содержат слово
  examples: [hydrobates-tethys, chaetura-cinereiventris]   # до 3 видов, в английском названии которых есть слово
```

`en`, `ru`, `note` пишутся руками; `freq` и `examples` не править, а пересчитывать:
`python3 scripts/vocab_freq.py --fill content/vocabulary.yaml` (частоты по `data/species_index.json` и
`data/texts/*.json`; без аргументов скрипт печатает самые частые слова — кандидатов в список). `examples: []` — оставить
примеры пустыми, когда в названиях слово в другом смысле (edge — опушка, а Pale-edged — «со светлой каймой»).
Значение с `: ` внутри брать в кавычки или переписывать через тире (это YAML).
