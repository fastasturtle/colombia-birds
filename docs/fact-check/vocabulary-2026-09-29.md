## Заметные исправления

- **antpitta**: «муравьиная питта» → «питтовая муравьеловка, питтуля» — старого варианта в данных нет вообще
  (Grallaria — питтовые муравьеловки, Grallaricula — питтули, Hylopezus/Myrmothera — торорои).
- **kingbird**: «королевский тиранн» → «тиранн» («королевский» — только Tropical Kingbird).
- **dove**: «голубь, горлица» → «горлица, голубка» (голубь — pigeon); **egret**: «белая цапля» → «цапля, белая цапля».
- **finch**: note про тохи была неверной (тохи — Passerellidae, не танагровые).
- **malar**: калька «малярная полоса» → «усы, скуловая полоса» (en.wikipedia Supercilium).
- **juvenile**: ювенильный наряд вырастает ещё в гнезде, а не «после гнезда».
- **vent**: + «область клоаки»; -vented в названиях — «-гузый». **nape**: + «зашеек».
- Цвета: в названиях eBird ru buff → светло-/бледно- (не «охристый»), sooty → «тёмный», dusky → «тёмный/бурый»,
  rusty → «ржавчатый», ruddy → «румяный», cinnamon → «коричневый», crimson → «карминный», glossy → «блестящий».
- **solitary**: + «отшельник» (улит-отшельник); **streaked/barred**: явное «не путать» — продольные пестрины vs
  поперечные полосы; **mottled** + «крапчатый»; **call** + «крик»; **sally** → «бросок, вылет за добычей».
- Места обитания: cloud forest → «туманный лес, облачный лес» (статья ru.wikipedia — «Туманный лес»);
  understory → «подлесок, нижний ярус»; swamp → «болото, заболоченный лес» (топь — трясина); riparian →
  «приречный, прибрежный»; scrub → «кустарниковые заросли»; grassland → «травянистые равнины»; woodland → «редколесье, лес».
