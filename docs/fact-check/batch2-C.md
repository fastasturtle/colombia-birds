# Факт-чек: партия 2, список C (котинги, туканы, дятлы, тинаму, куриные)

Карточки написаны 27.09.2026 по data/species, data/texts (Wikipedia en/es/ru), data/site_species.json и полевым знаниям.
Формат: `slug` — что проверить.

## Данные и таксономия (Data issues)

- `selenidera-reinwardtii` — русское имя в индексе с опечаткой («Золотошейний туканчик», должно быть «Золотошейный»); в тексте карточки использовано только английское имя. Исправить в источнике имён.
- `celeus-spectabilis` — Wikipedia (en) не называет Колумбию в ареале (Bolivia, Brazil, Ecuador, Peru), в data вид резидент ACO, а на маршруте «возможно» в Пуэрто-Асисе и на Плайя-Рике. Проверить статус и реальные колумбийские записи (не ошибки ли определения GBIF). В тексте сказано осторожно: «в Колумбии записей немного».
- `mitu-salvini` — «возможно» только в Исла-Эскондиде (650–1 600 м), а вид в Колумбии живёт до 600 м (Wikipedia; data 0–600, extreme 900). Проверить, откуда записи GBIF в радиусе точки (возможно, из низин вокруг заповедника).
- `cotinga-cayana` — та же проблема: «возможно» только в Исла-Эскондиде, вид обычно до 600 м (extreme 1 350). В тексте «в нижней части заповедника» — проверить.
- `ramphastos-ambiguus` — в data высоты 800–2 000 м (extreme 100–2 286), но тихоокеанский подвид swainsonii живёт от уровня моря (Wikipedia), и на маршруте вид «возможно» на Км 42 и в Финке Марагрикола (0–150 м). Данные BIRDBASE, похоже, описывают только черноклювую форму. Также проверить, какой подвид в Исла-Эскондиде/Дискосуре (в тексте — номинативный черноклювый).
- `ramphastos-tucanus` — ACO 2022 даёт МСОП VU, BIRDBASE/Wikidata LC (VU относился к «red-billed» по таксономии HBW). В тексте статус не упомянут.
- `pipreola-jucunda` — в data высоты 1 100–1 300 м (extreme 600–2 300), Wikipedia 600–1 900 м; основной диапазон в data кажется слишком узким. В тексте 600–1 900.
- `chamaepetes-goudotii` — в data максимум 3 500 м (это боливийские популяции); в Колумбии 1 100–2 500 м (Wikipedia). В тексте колумбийские высоты.
- `penelope-ortoni` — в data max_extreme 3 100 м; для предгорного вида (100–1 550 м) выглядит ошибкой.
- `cephalopterus-ornatus`, `selenidera-reinwardtii` — в data elevation min = "L" (строка вместо числа); проверить, что сайт это переваривает.
- `snowornis-subalaris` — ACO 2022 даёт NT, BIRDBASE и Wikipedia — LC. Также в data 500–1 400 м (эквадорские цифры), а для Колумбии Wikipedia даёт 600–1 500.
- `picumnus-lafresnayi` — похожий вид `picumnus-squamulatus` отмечен «возможно» в Финке Дискосура (Путумайо); Scaled Piculet — вид севера Колумбии, проверить, не ошибка ли определения в GBIF.
- `querula-purpurata` — в data максимум 1 200 м, Wikipedia для Колумбии до 1 400 м (мелочь).

## Размер (`size`) — пограничные решения

- `picumnus-lafresnayi` — 9–10 см, поставлен `hummingbird` по правилу «прочие крошки до 10 см». Решить общее правило для не-колибри около 10 см (та же проблема у `machaeropterus-deliciosus` в партии 1).
- `odontophorus-melanonotus` (23–28 см), `odontophorus-hyperythrus` (25–29 см) — поставлен `pigeon` (плотные птицы 320–380 г); по длине граница `thrush`/`pigeon`.
- `celeus-flavus` (24–27 см) — поставлен `pigeon`, граница с `thrush`.
- `ramphastos-tucanus` (50–61 см), `ramphastos-ambiguus` (47–61 см) — поставлен `crow` для единообразия с `ramphastos-brevis`, хотя крупные особи длиннее 55 см.
- `chamaepetes-goudotii` (50–65 см) — поставлен `larger`, а `penelope-montagnii` в готовой карточке — `crow`; сверить единообразие для гуанов.

## Внешность, голос и отличия

- `snowornis-subalaris` — отличие от Olivaceous Piha («хвост оливковый, низ зеленовато-жёлтый, держится выше») — по памяти.
- `querula-purpurata` — голос «ку-ваа» передан по памяти.
- `gymnoderus-foetidus` — «прыгает по веткам, как тукан» взято из es-Wikipedia; голос «низкий рёв» — по en-Wikipedia (фраза обрезана).
- `cephalopterus-ornatus` — «хохол с белыми стержнями перьев» — по памяти и по карточке `cephalopterus-penduliger`; «глаз светлый» — Wikipedia. Проверить также «глаз тёмный» у penduliger.
- `cotinga-maynana` / `cotinga-cayana` — отличия (ровный тон против «блёсток», размер и цвет пятна на горле, цвет глаза) — частично по памяти; у самки cayana тёмный глаз (es-Wikipedia).
- `pipreola-chlorolepidota` — в Колумбии вид «близкий к угрожаемому» (ACO NT, Libro Rojo NT) — сверить формулировку.
- `pipreola-lubomirskii` — нижняя граница (в тексте 1 200 м по data; Wikipedia 1 500 м); Эль-Энканто лежит на 1 350 м.
- `andigena-nigrirostris` — «почти-эндемик Колумбии» — по флагу near_endemic в data; «голубая кожа спереди и жёлтая сзади глаза» — по Wikipedia; окраска клюва подвида spilorhynchus на юге маршрута.
- `ramphastos-tucanus` — утверждение, что в Колумбии живёт черноклювый подвид cuvieri (Cuvier's Toucan), и отличие от Channel-billed по длине клюва и голосу — по памяти; жёлтое надхвостье и красная полоса под белой грудью — проверить для cuvieri.
- `pteroglossus-pluricinctus` — голос «ти-сип»/«кьюк» — по памяти.
- `picumnus-lafresnayi` — голос и отличие от Scaled Piculet («спина бурая») — по памяти.
- `campephilus-gayaquilensis` — двойной стук «ток-трррр» и отличия от Lineated Woodpecker (белая полоска на щеке, пёстрое горло) — по памяти.
- `ramphastos-ambiguus` — цвет голой кожи у глаза по подвидам (жёлто-зелёная у swainsonii, голубая у номинативного) — по en-Wikipedia; «надхвостье белое» — Wikipedia (es даёт «кремовые»).
- `celeus-flavus` — голос («смеющаяся серия») — по памяти.
- `celeus-spectabilis` — голос описан расплывчато; «специализируется на муравьях в стеблях бамбука» — по Wikipedia для Перу/Бразилии; в Эквадоре связан с цекропиями и тростником.
- `selenidera-reinwardtii` — «жёлтый воротник на затылке» — по en-Wikipedia (узкая жёлтая полоса между чёрным и спиной); голос «гррок» — по ru-Wikipedia.
- `chamaepetes-goudotii` — «приходит на кормушки с бананами» — по en-Wikipedia (в общем); на маршрутных лоджах не подтверждено, поэтому `feeder` не поставлен.
- `odontophorus-melanonotus` — отличие от Rufous-fronted Wood-Quail (рыжий лоб и низ, белый полуошейник) — по памяти.
- `crypturellus-cinereus` — отличие от Undulated Tinamou (волнистые полоски, беловатое горло, песня из 3–4 нот) — по памяти; «подклювье жёлтое» — по en-Wikipedia.
- `odontophorus-hyperythrus` — отличие от Marbled Wood-Quail (оранжево-красная голая кожа у глаза) — по памяти; присутствие Marbled в предгорьях Путумайо (Исла-Эскондида, «возможно»).
- `penelope-ortoni` — «клюв светлый» (es-Wikipedia: «pico color marfil») и «голубое голое кольцо» — сверить; отличие от Andean Guan (размер, чешуя) — по памяти.
- `mitu-salvini` — голос («гулкое бормотание перед рассветом», «резкие свисты») — по памяти; отличие Nocturnal Curassow (жёлтая и голубая кожа у глаза) — по памяти.
