# Журнал факт-чека

## 2026-09-27 — пилот: 10 карточек видов (партия 1)

Скилл `fact-check`, проверяющий — субагент (Opus). Данные проекта + Wikipedia (en/es/ru через `data/texts/` и WebFetch),
eBird (только чтение), сниппеты Birds of the World из поиска. Предложения о свободных днях в Боготе не трогались
(их одновременно правил другой агент). Сборка не запускалась; frontmatter, traits и `similar` проверены скриптом.

Счёт: утверждений / подтверждено / исправлено / удалено / непроверяемо.

- **fulica-ardesiaca** — 22 / 17 / 4 / 1 / 1
  - Английское имя: в тексте первым шло Andean Coot; по eBird/Clements (канон проекта) — Slate-colored Coot, Andean — имя IOC (data/species/fulica-ardesiaca.json).
  - Голос «кук», «пит» (по памяти) заменён на «чррр»/«хррп», у самки стрекотание (en.wikipedia Andean coot).
  - Удалено «выходит пастись на прибрежные луга» (поведение американской лысухи, источника нет); добавлено кормление с плавучей растительности, ныряние (en.wikipedia).
  - «Только в Нариньо» смягчено до «на крайнем юге, прежде всего в Нариньо» (en.wikipedia: «Andes of southern Colombia»).
  - ❓ «клюв белый с тёмным кольцом у конца» для American Coot подвида columbiana не подтверждён (BOW закрыт); оставлено как общий признак вида. American Coot на Ла-Коче в site_species «точно» (267 записей GBIF) — подтверждено данными, но возможны ошибки определения.
- **numenius-phaeopus** — 18 / 17 / 1 / 0 / 0
  - Добавлено, что колумбийские птицы — Hudsonian Whimbrel (N. hudsonicus), отдельный вид в eBird/Clements с 2025 (https://ebird.org/news/2025-taxonomy-update); ru: «американский средний кроншнеп» (ru.wikipedia). **Нужна правка маппинга ACO→eBird в пайплайне и переименование карточки в numenius-hudsonicus** (data/ не трогал).
- **oxypogon-guerinii** — 19 / 16 / 2 / 0 / 1
  - Голос: «тихий, не помогает» → описана серия «тии… тии…» самцов при погоне (en.wikipedia Green-bearded helmetcrest).
  - Отличие Chalcostigma heteropogon: хвост «оливковый» → «бронзовый» (Bronze-tailed Thornbill).
  - Высоты 3 000–4 200 м по Wikipedia подтверждены; в data 3 000–5 200 (BIRDBASE, старый объём вида) — не править в тексте.
- **heliodoxa-imperatrix** — 20 / 18 / 1 / 0 / 1
  - Отличие H. jacula: «хвост почти не вырезан» неверно — у самца хвост заметно вильчатый; добавлены размер 12–13 см и белое пятно за глазом (en.wikipedia Green-crowned brilliant).
  - ❓ Посещение кормушек лоджей Нариньо не подтверждено источником (правдоподобно, оставлено).
- **capito-squamatus** — 17 / 16 / 1 / 0 / 0
  - Отличие C. quinticolor: «жёлтые полосы на спине» → жёлтая «галочка» на спине, горло и грудь жёлтые (en.wikipedia Five-colored barbet).
- **anisognathus-igniventris** — 16 / 15 / 0 / 0 / 1
  - Приметы и голос («беспорядочный звенящий набор») подтверждены (es/ru.wikipedia, eBird). Уточнение: на юге Колумбии (Нариньо, Уила) подвид erythrotus, в Восточных Андах (Чикаке) — lunulatus; оба в группе lunulatus, приметы общие (ru.wikipedia).
  - ❓ Русское имя: в ru.wikipedia «Краснобрюхая горная танагра», в проекте (eBird ru) «Огненнобрюхая танагра» — оставлено по канону проекта.
- **tangara-chilensis** — 17 / 14 / 2 / 0 / 1
  - «Грудь и брюхо бирюзовые» → середина брюха чёрная (Birds of the World, описание оперения, по сниппету поиска).
  - Поясница: низ спины красный, надхвостье по подвиду красное или жёлтое (BOW; en.wikipedia). ❓ Какое надхвостье у путумайских птиц (T. c. chilensis), по открытым источникам не установлено; es.wikipedia противоречит сам себе.
- **machaeropterus-deliciosus** — 18 / 14 / 3 / 1 / 1
  - Голос: «почти не пользуется голосом» неверно — у тока «сиит» и серия громких «кеа!» (en.wikipedia Club-winged manakin).
  - Механика звука: не «ударяет перьями друг о друга», а трясёт поднятыми крыльями >100 раз/с, жёсткое перо чиркает по ребристому (en.wikipedia).
  - Удалено «наклоняются вперёд» (не подтверждено); добавлено «тонкие ветки до 7 м».
  - ❓ Высоты: в карточке 600–1 900 м (BIRDBASE), Wikipedia для Колумбии даёт 400–1 800 м; оставлено по данным проекта.
- **cistothorus-apolinari** — 17 / 14 / 2 / 0 / 1
  - Подвид hernandezi: не «выше 3 000 м», а 3 800–3 900 м, только массив Сумапас (en.wikipedia Apolinar's wren).
  - Голос переписан по Wikipedia: трещащие трели со скрежещущими нотами; дуэты описаны у hernandezi.
  - ❓ Ключевые приметы описывают номинативный подвид; у hernandezi (Сумапас, «точно» по данным) низ заметно белее — стоит добавить при следующей правке.
- **penelope-montagnii** — 18 / 15 / 2 / 0 / 1
  - «Размером с небольшую индейку» неверно (500–840 г): похожа на индейку по складу, но гораздо мельче (en/ru.wikipedia).
  - Голос: добавлены мягкие хриплые серии «чоу-чоу» (es.wikipedia).
  - ❓ «Там, где не охотятся, подпускает близко» — не подтверждено, безвредно, оставлено. «Точно в Чингасе» — необязательная точка вне программы (формулировку правит другой агент).
