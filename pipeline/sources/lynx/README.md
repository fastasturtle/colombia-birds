# Lynx «Birds of Colombia» — транскрипции

Книга: **Hilty, S.L. (2021). Birds of Colombia.** Lynx and BirdLife International Field Guides.
Lynx Edicions, Barcelona. 608 с., 1 965 видов. ISBN 978-84-16728-24-4 (flexi), 978-84-16728-23-7 (hardcover).
По ней готовится группа (см. `docs/DECISIONS.md`, № 15). Текст книги под копирайтом: здесь только
служебные разделы (указатели и список литературы), нужные для ссылок «страница в книге».

## Откуда

Владелец сфотографировал развороты (2026-09-27), агенты Claude транскрибировали фото постранично
(каждая страница нарезана на колонки, каждая колонка прочитана и сверена по перекрытиям). Автоматического
OCR не было: в облачной сессии нет tesseract, и качество фото (перспектива, размытие у корешка) его бы не
выдержало.

## Формат

`## page N`, `## column N`, одна запись на строку в порядке печати; жирные заголовки групп `**Ani**`
(с номером после `**`, если есть), подпункты с отступом в два пробела; строка `**Chat**, Rose-breasted 499`
эквивалентна заголовку плюс подпункту; переносы строк книги склеены; буквы-разделы `# A`; нечитаемое `??`;
после `## notes` — примечания транскрибёра, парсер их не читает. Подпункты могут продолжаться через
границы колонок и страниц без повтора заголовка. Полная спецификация в докстринге `pipeline/steps/build_lynx.py`.

## Известные оговорки

- Шрифт книги не различает «rn» и «m»: транскрибёры писали нормативную латынь (Doliornis, hornbyi, inornata).
- Опечатки книги сохранены как есть: `erythropthalmus, Coccyzus`, `boissonneauii`, `martinicus`,
  `Hypocnemoides 553` и `Myrmoborus 553` (напечатано именно так).
- Скобка в `epithet, Genus (x)` — вид, к которому книга относит таксон (`andinus, Sclerurus (mexicanus)`),
  а не подвид; в JSON поле называется `subspecies`.
- Ошибки распознавания правятся прямо в этих файлах (руками агента, по фото), затем
  `cd pipeline && uv run python run.py lynx build`. Различия таксономии (книга 2021 vs eBird/Clements 2025) —
  в `pipeline/mappings/lynx_names.json`, а не в текстах.
