| 18 | Вероятность и «интересные» (27.09) | Для каждой пары (вид, место) три состояния только по осенней (сен–ноя) частоте GBIF в радиусе локации: «Точно увидим» (`sure`, ≥ 1 % осенних записей птиц), «Возможно» (`maybe`, 0,1–1 %), «Вряд ли» (`unlikely`, < 0,1 %, < 3 осенних записей или вида нет в списке GBIF локации). Пороги — константы в `pipeline/common.py`. Для дня — лучшее состояние по локациям дня, для списка без места — лучшее по всем локациям маршрута. «Интересная» (★, бывшая «изюминка») — цель из отчётов о поездках для этой локации, эндемик или почти-эндемик Колумбии (`near_endemic` в `species_index.json`, нет поля = false) или вид с узким ареалом; от состояния не зависит, цели из отчётов не выкидываются (без записей GBIF — «вряд ли» + ★). На всех списках (дни, локации, семейства, «Все виды», определитель) один фильтр из двух переключателей: «Точно · Точно и возможно · Все» (по умолчанию «Точно и возможно») и «Все · Интересные · Почти-эндемики · Эндемики» (по умолчанию «Все»); уровни вложены: Эндемики ⊂ Почти-эндемики (почти-эндемики и эндемики) ⊂ Интересные (★) ⊂ Все. Выбор общий для сайта (`localStorage` `cb.filter`, `{level, tag}`, tag = all/int/near/end; старый `interesting: true` читается как «Интересные»); счётчики на страницах и в фасетах определителя считаются под текущий фильтр, карточки дней на главной — под фильтр по умолчанию (без JS). Значки на плитках и строках: ★ интересная, «энд.» эндемик, «п.-энд.» почти-эндемик (27.09, переключатель вместо «Только интересные»). |
| 19 | Виды вне ACO 2022 (27.09) | База списка видов остаётся ACO 2022, но в индекс разрешено добавлять виды из Clements/eBird 2025, которых в ACO нет (сплиты после 2022, залёты), если они подтверждены записями GBIF/eBird на точках маршрута. Таксономия имён и сплитов следует eBird/Clements 2025 (так называют птиц гиды). Такие виды помечаются в данных `source: clements2025`. |
| 20 | Офлайн (28.09) | Сайт статичный, офлайн — рукописный service worker без Workbox и без переключателя «офлайн-режим»: сеть либо есть, либо нет. Пока сеть есть, выигрывают свежие данные (HTML — сначала сеть в обход 10-минутного кэша GitHub Pages, таймаут 3 с). Ничего тяжёлого не качается без явной кнопки: при обычном просмотре кэшируется только открытое и сама страница «Офлайн». Пакет (кнопка на `/offline/`) = все страницы + `_astro` + миниатюры и средние фото (≈ 430 МБ), крупных фото нет (без сети подменяются средними). Качает страница, не worker: 6 потоков, прогресс всегда пересчитывается по содержимому кэша, поэтому остановка и закрытие вкладки ничего не теряют. Версии: build id в `version.json`, `sw.js` и `<meta name="build-version">`; у файлов из dist — хэш содержимого, у фото — ключ (фото на R2 неизменяемы). Два кэша `pages-v1`/`media-v1` не зависят от сборки. На iPhone пакет качать в приложении с экрана «Домой» (своё хранилище). Удаление — второе нажатие «Точно удалить?» вместо `confirm()`. |
